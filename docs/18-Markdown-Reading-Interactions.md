# Markdown Reading Interactions

日期：2026-11-10。DevTabs 0.4.0。基线：`a816ca2`。本轮完成六项阅读交互、引用层级、表格阅读，以及文件树、预览和编辑区滚动条。

## 功能与操作

| 项目 | 操作与结果 |
| --- | --- |
| 代码块复制 | 语言右侧 `[Copy]` 复制完整代码正文，包含空行、Tab 和换行，不包含围栏、语言标签和显示补白；成功短暂显示 `[Copied]`。横向滚动不移动按钮。 |
| 链接跳转 | 单击并在同一位置松开打开链接；拖动仍为选择。HTTP/HTTPS 用系统浏览器，文件相对当前文档目录解析，在预览区打开；支持百分号编码的路径、中文锚点和文件后的 `#标题`。错误路径保留当前文档并报告错误。 |
| 标题大纲 | Markdown 阅读模式点击预览右上角 `[T]`，或预览焦点按 `T`、F2 → Heading outline，在按钮下方打开小型下拉浮层；输入/粘贴过滤，鼠标点击标题或 ↑↓、Enter 跳转，滚轮浏览。再次点击按钮、点击外部或 Esc 关闭；外部点击不会穿透。大纲包含尚未排版和折叠区域里的标题，跳转时展开必要的祖先 details。 |
| 阅读位置 | 同一 Sidebar 实例内保留最近 64 个文件的源码位置、横向位置、模式和折叠状态；缩放、源码/阅读切换后按源码位置重新定位。跳转历史最多 64 项，`Alt+Left` 或 F2 → Reading back 返回。进程退出后不持久化这些位置。 |
| 图片入口 | 图片保留说明和地址；点击在系统默认应用打开本地图片，网络图片交给浏览器。预览不下载图片，不增加终端图片协议依赖。 |
| 脚注 | 启用 pulldown-cmark 脚注语法；点 `[^id]` 到定义，点定义前的 `↩` 或 Alt+Left 返回。 |
| 折叠内容 | 支持块级 `<details>` / `<summary>`，显示 `▸` / `▾` 和摘要；点击切换。支持嵌套和 `open` 默认展开。折叠只影响阅读副本，编辑和保存仍使用完整源码。 |
| 引用层级 | 每层 `│ ` 缩进，嵌套交替使用引用色和弱化色；续行、空行保留竖线，极窄宽度遵守现有字素裁剪规则。 |
| 表格阅读 | 普通宽度允许表格超出视口并横向查看，以 `max(视口宽度, 512)` 为列分配宽度上限；内容区不足 40 列继续使用已有字段/值回退。表体滚动时固定表头和分隔线；表头占满视口时不固定。 |
| 滚动条 | 右边框显示纵向滚动条；预览/编辑区当前可视行存在溢出时，底边框显示横向条。文件树按已展开节点计数。点击轨道定位、拖动滑块连续定位，释放后结束；内容能放下时隐藏。滚动条不占用正文列。 |

预览 PageUp/PageDown 使用当前视口高度；已完整排版的文档不会滚动到末行以外。编辑区复用 TextArea 的滚动行为，光标跟随保持在视口内，滚动不修改文本和撤销历史。

文件跳转继续遵守既有未保存修改提示；取消不会切文件。网页和图片只在主动点击后打开。仅处理支持的链接种类，不把链接交给 PowerShell 执行。

## 实现与边界

- `preview/reading.rs` 保存源范围对应的标题、链接、图片、脚注和 details 索引；展示文本、源码和交互索引相互独立。标题自动锚点保留 Unicode 字母/数字及 `-`、`_`，空白转 `-`，重复标题增加数字后缀，也支持显式 `{#id}`。
- details 标签和隐藏正文按原字节长度遮蔽，仅改变渲染副本；摘要注入带源范围的段落。代码围栏内字面 HTML 不作为折叠标签执行。支持 Markdown 文档常见的块级 details，不实现任意 HTML DOM/CSS/JavaScript。
- 普通 Markdown 的索引事件直接复用到块缓存，避免为大纲再解析一次；需要数学遮蔽或折叠过滤时才重建对应事件。标题去重使用集合，折叠范围合并后用二分定位，避免嵌套数量带来平方扫描。
- 代码复制正文只随已经排版的块生成；复制按钮和语言标签不进入显示文本搜索、选择和源码坐标。表格行携带相对表头位置，绘制和点击命中使用相同的屏幕行映射。
- 沿用全局扫描、按需块排版和有界彩色缓存。大纲和拖动可以跳到未排版的位置；第一次跳往深处仍需排版前缀，工作在后台完成，不能声称具有常数时间的随机访问。
- Markdown 尚未排版完整时，纵向条使用源码字节比例表示大致位置，拖动请求对应源位置；完成后使用显示行数。一轮拖动固定其坐标单位，避免后台完成导致单位突然改变。不会为了计算精确总显示行数而在首次打开时排版全文。
- 滚动条绘制复用 Ratatui `Scrollbar` / `ScrollbarState`；本地仅处理坐标与拖动，拇指命中范围从同一 widget 生成。文件树统计只在视图失效时更新，横向溢出检查仅扫描可视行。
- 缩放窗口和切换模式时，旧宽度、旧主题或旧模式的异步结果会被丢弃，避免提前消费待恢复位置。记录位置属于源码偏移；外部大幅改写文件后只能做近似定位。

### 下拉大纲调整

大纲改为锚定预览区右上角按钮的浮层，不再居中覆盖整个界面。宽度随标题长度调整，限制为 24–48 列并适应预览区；最多显示 10 项，缩窄窗口后仍保持在预览区内。过滤行、层级缩进和整行选中高亮保留，长列表滚动后按下与松开之间不重排条目，拖动不触发跳转。

修改前新增按钮回归失败，确认旧版缺少入口；修改后 `markdown_reading`、`editor_windows`、`markdown_viewport` 合计 **45 项通过，1 项忽略**。新增四项回归覆盖浮层锚定与尺寸、鼠标跳转与外部关闭、滚动过滤与窗口缩放，以及长列表滚动后的点击稳定性。Clippy 拒绝警告、fmt、diff 检查和 Release 构建通过；真机 UI 仍由用户验收。

边框遮挡修复：正文的双列字符可能从浮层左边界外跨入边框；仅使用 `Clear` 清空浮层内部会留下字符前半部，终端差分输出因此跳过边框。绘制浮层前清除跨界字符的起始单元格，保留该格背景；关闭后由正文正常重绘恢复。新增回归在修复前复现左边框缺失，修复后覆盖三种宽度、双主题、重复打开/关闭和正文恢复，相关测试合计 **46 项通过，1 项忽略**。
