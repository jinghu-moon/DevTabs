# Markdown Viewport Optimization

日期：2026-11-10。第二项优化，基线 `b65e7a2`。数据：[02-Markdown-Viewport.json](performance/02-Markdown-Viewport.json)。

## 实现

Markdown 的行数取决于实际换行、嵌套、表格列宽和空间布局，不能直接用源文件行号定位显示行。新路径先建立全局事件与顶层块索引，保留跨段引用解析；随后按需布局完整块，直到覆盖当前视口及 16 行预读。第一次跳往尚未确定几何的深处，仍需布局前面的块，不能宣称随机跳转没有前缀工作。

已经确定的纯文本行和源坐标保持稳定，新布局向后追加；窗口保存可视范围的样式。完整块的样式缓存按最近使用淘汰，目标上限 64 块、512 行；单个超大原子块可单独占用缓存，仍受既有 30000 行/100000 Span 限制。表格、列表、公式和图形不会被分割后独立排版。保留全局逻辑行是为了支持跨屏选择、复制与搜索，不等于保留所有彩色 Span。

索引阶段只识别和保护公式边界，TeX 转 Unicode 留到布局相应块时执行。代码块高亮与 Mermaid 生成同样只在该块被布局时执行。全局源码扫描和事件索引依然存在；大块本身的工作量也没有消失。

滚动时保持 Markdown 排版，不切换成源码。已知行立即显示，尚未确定的区域显示加载提示，后台完成后补齐。全文搜索、复制全文及 End 键会请求后台补齐布局，避免把已布局前缀误当成全文；它们因此可能等待剩余布局。End 最终定位真实末尾，搜索仍以显示文本与原有坐标为准。

文件线程和渲染线程继续分离。快照共享逻辑文本及源映射，不通过 UI 锁访问后台缓存。公开的完整渲染函数保留为参照与直接调用路径，真实 Sidebar Markdown 预览使用按块缓存。

## 数据与判定

相同 73406 字节、1501 个块的 Markdown，100×40 TestBackend，Release 五次打开，语法与主题预热一致，负载串行执行：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 打开到首屏完成，中位数 | 38.30 ms | 6.91 ms |
| 首屏打开时生成的逻辑行 | 3501 | 53 |
| 首屏布局的块 | 全部 | 23 / 1501 |
| 完整彩色 Text 的 Span / 当前窗口彩色 Span | 11501 | 167 |
| 外部采样进程峰值工作集 | 18.07 MiB | 16.66 MiB |
| 外部采样私有内存峰值 | 8.47 MiB | 6.88 MiB |

打开耗时减少约 82%。内存来自独立外部采样运行，不能与无采样耗时混作同一次运行；工作集是最后存活采样点看到的系统峰值，私有内存是名义 5 ms 间隔的采样峰值。新实现另有 30 个中性逻辑 Span 和完整块缓存，不能把 167 个窗口 Span 宣称为全部保留内存。

六进程规模测试首次失败：编辑/撤销/搜索反馈约 81/118/415 ms。后两次保持原门槛通过，第一次失败原因未确定，三次数据均保留，不能据此保证不存在计时波动。最终预览/编辑工作集总和 93.59 MiB，保存采样峰值 97.04 MiB；未放宽 50 ms 反馈、100 MiB 内存等既有断言。

102 项普通工作区测试通过，包含新增五项：首屏不布局全文；多宽度和双主题下对照完整渲染，逐行核对文字、样式和源坐标；滚动稳定与缓存约束；全文搜索与 End 到达真实尾部；索引阶段不转换 TeX。原有编辑、冲突检查、终端、文件树、Markdown/公式/图形回归继续通过。fmt、Clippy（拒绝警告）、Release 热点和大目录测试通过。

核心耗时和保留内存有收益，保留并提交第二项；规模测试的首次计时异常作为未确定原因的观测保留。

## 复现

```powershell
cargo test --workspace --all-targets --locked -- --test-threads=1
$env:DEVTABS_MARKDOWN_REPORT = 'artifacts/markdown-viewport-after.json'
cargo test --release --locked --test markdown_viewport markdown_viewport_workload -- --ignored --test-threads=1
```

`Document::markdown_stats()` 提供索引块数、累计布局块数、缓存命中、缓存块/行数、已知行数和布局是否完成。`DEVTABS_PERF_DIR` 下新增聚合计时 `markdown.viewport_layout`；默认不输出日志，不记录源码或路径。

公式预处理属于 Apache-2.0 改编源码，已保留声明并更新来源哈希与修改记录。后续第三项单独评估编辑引起的增量失效，不混入本次提交。
