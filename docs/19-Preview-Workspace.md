# Preview Workspace

日期：2026-11-10。基线：`94afc71`。在既有文件树、预览、编辑和 Markdown 阅读交互基础上补齐八项功能。

## 功能和操作

快捷键在预览获得焦点时生效；编辑器里的字母仍作为正文输入。全部新增操作也可从预览 F2 菜单进入。

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| 最大化 / 恢复 | 右上 `[Z]`、`Z`、F2 | 预览临时覆盖工作区正文；再次操作恢复原树、Agent、Debug 布局。会话继续运行，按源码位置恢复阅读位置。 |
| 代码自动换行 | `[W]`、`W`、F2 | 默认关闭；开启后源码预览和 Markdown 代码块按正文宽度折行。保留字素、样式、源码映射，复制不插入显示换行。源码行号显示原始行号，续行留空。表格、数学、Mermaid 保持空间布局。 |
| 阅读进度 / 定位 | 底部状态、`G`、F2 | 显示源码行 / 预览总行数、源码字节百分比、当前 / 总搜索匹配数。定位浮层接受从 1 开始的源码行号，或 `0%`–`100%`；Enter 跳转，Esc 取消，输入错误留在浮层中提示。 |
| 当前章节大纲 | `[T]`、`T`、F2 | 打开时自动选中当前阅读源码位置之前最近的标题，并将其滚入列表。长标题按字素保留前缀和层级、尾部显示省略号。保留过滤、鼠标、滚轮和跳转。 |
| 增强搜索 | `/`、F2 | 输入查询时 `Alt+C` 切大小写敏感、`Alt+W` 切全词、`Alt+R` 切正则；选项显示在底部。Enter 确认，`n` / `N` 导航，Esc 退出输入。无效正则提示错误，已有文档和编辑内容保留。跨显示换行匹配会在两行高亮，只计一个匹配。 |
| 文件差异 | `[D]`、`D`、F2 | 文件外部变化后对比最近的旧快照与新磁盘版本；有未保存修改时对比编辑缓冲区与最近读取的磁盘版本。显示统一 diff、增删行数、三行上下文；↑↓、PageUp/PageDown、Home/End、滚轮浏览，←→ 横向滚动，Esc 关闭。无变化显示 No changes。 |
| 文件标签页 | 标题下方文件条、Alt+PageUp/PageDown、F2 | 同时打开最多 8 个文件；单击切换，标签条上滚轮切换。宽度有限时显示当前文件附近的标签。切换保留源码位置、模式、折叠、换行和搜索选项；关闭当前标签显示相邻文件。未保存切换 / 关闭沿用保存、放弃、取消提示。 |
| Markdown 源码对照 | `[V]`、`V`、F2 | 左边阅读，右边带行号与语法高亮的源码，两者使用同一内容快照。左侧滚动、标题 / 搜索 / 行号跳转后右侧跟随；在右侧滚轮或点击源码行会定位左侧。右侧支持横向滚轮。支持编辑器的 Preview current content，包含未保存内容。 |

正文仍保留四周留白，滚动条继续在边框绘制。进度使用工作区底部状态，不覆盖横向滚动条。多个标签时文件条放在标题下方，正文保留上方空行；进入编辑器后文件条隐藏，编辑器继续使用自己的坐标和快捷键，F2 返回预览后恢复文件条。

文件条使用三行高度的独立标签栏：每个标签有完整四边框，标签之间留间隙，当前标签显示 `●`、加粗和强调色边框，深浅主题均有独立背景。标签优先显示文件名，同名时补父目录，按字素截断；单个标签最多 32 列，窄窗口减少可见数量。标签上边框紧接预览窗口边框的下一行，下方到正文之间留一行空白；三行标签均可点击或滚轮切换。样式回归在修改前失败，修改后验证文件名优先、双主题、完整边框、顶部无空行、下方留白、当前状态和底边点击；相关阅读、视口及工作区测试 **47 项通过、1 项忽略**，Clippy 通过。

对照模式正文不足 36 列时暂时只显示阅读区；放大或最大化后自动恢复两栏。关闭对照恢复完整阅读宽度。对照是只读视图，编辑仍通过显式 Edit source 进入。

## 实现和边界

- `sidebar/features.rs` 管理预览布局、定位、标签和对照交互；每个 Document 保存自己的显示偏好和源行索引。现有 Workers 承担代码换行、源码高亮和 diff，UI 线程不读文件或计算 diff。
- 复用现有 `regex 1.13.1`，增加 `similar 3.2.1`（实现时 crates.io 最新版本）。正则编译限制 1 MiB，DFA 缓存限制 1 MiB，最多保留 20,000 个逻辑匹配；到上限时明确提示。默认保留原有忽略大小写和重叠匹配行为。
- 自动换行建立原始行、字符范围与显示行的投影；搜索、复制、源码跳转和高亮窗口共用该映射。显示投影超过 50,000 行时提示并保留不换行视图，避免极窄宽度放大内存。代码块复制仍复制完整原文。
- Markdown 仍按视口排版；换行只处理当前已知前缀，不主动完整排版全文。搜索或复制全文沿用已有完整布局路径。跳向深处仍可能需要后台排版前缀，不宣称常数时间随机访问。
- 源码对照复用按视口高亮，只缓存当前窗口的颜色；源码行索引只在内容快照变更时重建。右侧列出同一源位置起的源码行，采用语义位置联动，不承诺与左侧显示行逐行等高。
- 非活动标签保留有界文件快照和阅读状态，释放 Rendered、高亮窗口和对照缓存；返回时重新读取验证磁盘并按需渲染。第九个文件淘汰最早打开的标签。未保存内容不进入淘汰流程。标签和偏好仅在当前进程生效。
- diff 使用最近一次内容变化快照，非 Git HEAD 对比；切离文件时释放旧差异快照。首次读取无历史时显示无变化；受原有 1 MiB、10,000 行等预览上限约束。算法设置 250 ms 计算期限，极端输入可使用粗粒度差异；不会修改或应用补丁。
- 异步结果以路径、任务 ID、宽度、主题和内容版本核验。浮层复用跨边界宽字符清理，避免中文正文遮挡边框。
