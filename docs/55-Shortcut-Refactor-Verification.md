## 阶段 1 细节

编译索引先按闭合上下文集合继承父级有效值，再计算子级差异，与 TOML 条目顺序无关；显式用户键仅在重叠的实际区域抑制默认键。拒绝 add/remove 交集和额外序列前缀；退役命令/区域保留诊断，失效首选回退但不复活删键。终端占用清单完全由有效绑定推导。

Win32 原始记录不变，匹配层将 AltGr 的可打印结果及 IME packet 保留为文本，标点字符的布局 Shift 归一化，字母 Shift 仍有语义。Plus 有规范拼写；系统安全组合拒绝注册，输入法/系统风险组合共享警告来源。

账本按物理键维护最新控制位，失焦普通键先释放，左右 Ctrl/Alt 分别清位，Unicode 代理对补发保留两个记录；原目标/代次不随 UI 焦点改变。保守抑制遇到复焦后重按会显示“松开后再按一次”。固定导航/文本可重复，注册业务遵守命令 repeat 策略。新增 9 个契约/原生夹具测试，并保留原有测试。

## 阶段 2 细节

Ctrl+P 默认经真实转发分支透传，删除侧栏的遗留截获分支。`panel.quick_open` 可显式扩展到 `terminal.input`，该区域不继承面板 Ctrl+P 默认。新增空默认的 `terminal.send_quick_open_key`；两个原键发送命令在工作区菜单都有鼠标出口。序列记录原始终端/连接代次/协议；发送形成一次完整周期，不将输入投递给后来聚焦的终端。首个前缀 Down 归 SequencePending，重复 Down 不会当作第二次按下；新增真实物理周期轨迹测试。

管理页的录制/文本/前缀/导入/明确替换共用校验与风险确认。原生录制在 Release 后形成候选；无物理记录的通道注明能力限制，仍可手写。组合键与前缀序列分为显式录制操作，Esc/Enter 可录且有鼠标完成/取消。导入先预览再确认，仅改共同草稿。按键测试覆盖闭合上下文集合，新一次未命中会取消上次首选候选。

恢复绑定/当前命令可保留历史备注，另有清除单条/全部备注操作；恢复全页提供保留/清除备注两个按钮。删除自定义别名不会伪造 remove tombstone，允许给它附备注。失效配置可查看并明确删除；默认抑制/失效首选说明进入详情。导出 TOML 差异与完整有效 JSON 目录分开，JSON 明确不可作为用户差异导入；均取已提交设置，不提前写草稿。

旧测试中“恢复即丢备注”“导入即改变草稿”“一次录制混入两个非前缀 chord”的预期已按规格改为更强的行为断言，并新增风险确认、完整原生周期、历史别名及有效目录测试；保存失败、冲突、取消和已有保护测试保留。

## 阶段 3 细节

新增独占 options/presets/queue/instances/history/attention/palette/batch 上下文。业务快捷键进入 `shortcuts/modals.rs`，默认大小写别名显式登记，修饰键精确匹配。选项字段和确认表单继续使用固定控件输入。鼠标激活预设/实例/面板直接发送命令 ID；共同包装保留异步保存失败后恢复原表单的保护。

总览接入物理键账本，打开弹层的同次按下不会在关闭后连发；文本与导航可重复。原生录制仍在账本前观察 Down/Up，背景便签等命令无法穿透弹层。增加真实重绑与物理按下周期测试。

真实 PTY 的连续 Esc 验收实际发现一个潜伏缺陷：粘贴分隔符探测缓冲了 Esc Down，却丢弃其 Up。修复为同序缓冲全部记录、仅用 Down 文本识别分隔符；普通 Esc 与按完整周期传入的中文粘贴分别有夹具断言。没有升级宿主/子终端键盘协议，未修改终端用户配置。早期失败日志保留，最终以修复后的重跑结果为准。

## 阶段 4 细节

终端菜单、资源计划/归档、通知及轮次审阅业务按键统一登记；局部键盘及鼠标通过命令 ID 进入原业务处理。资源操作继续验证当前任务、操作 ID 与显式确认；输入搜索/范围时文本不触发背景命令。新增重绑、精确修饰键、长按一次、跨模态拒绝与退出保护测试。

移动/缩放优先于普通工作区匹配；终端选区使用封闭上下文，仅开放选区复制与退出命令及原生滚动/取消。输入所有权上下文包含会话/连接代次、焦点、模态类型与输入子状态，避免原位位运算冲突。失焦/平衡/手势清理旧序列目标，直接发送命令不复用已取消序列的捕获目标。退出选区无需重新请求终端历史。

第一次新增激活测试使用了无连接的收起终端，期望焦点切换与实际安全边界矛盾；夹具改为停靠目标并完整重跑。最终 251 单元、7 真 PTY、4 审计、1 差异、25 工作区测试全部通过，13 忽略；初跑日志保留为 `phase4/fixture-first.log`。

## 阶段 5 细节

树激活、差异跳转/复制、书签定位/删除/备注/刷新、信息复制、查找选项、快速打开及大纲定位进入注册表。局部菜单使用封闭上下文及共享 Router，单键和前缀序列均按用户有效表执行；删除原键后没有遗留硬编码兜底。鼠标的书签、大纲与快速打开直接发送命令 ID。侧栏报告业务按键归属，原生适配层按完整物理周期抑制连发。

继续使用既有异步请求、pending 检查、只读限制、未保存保护和选中目标；备注/搜索文字及导航仍由控件处理。新增真实局部重绑、精确修饰键、序列、模态隔离与 pending 保护测试。原预览测试将“不带 Shift 的大写 N”改为显式 Shift+N，并新增 Alt+N 不触发断言，符合本次精确匹配的有意变化。夹具清理遇到 Windows 监听句柄延迟释放，仅对分享冲突/目录未空做最长三秒重试，保留所有业务断言。

最终 253 单元、13 编辑、28 预览、7 侧栏、7 真 PTY、4 审计及 1 差异测试通过，12 忽略；初跑及最终日志均保留。


## 阶段 6 细节
