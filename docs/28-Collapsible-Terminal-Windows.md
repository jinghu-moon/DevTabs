# 28-Collapsible-Terminal-Windows

## 当前决定

终端“悬浮”是 **DevTabs 当前 TUI 内的浮层面板**。Agent、Debug 和额外命名会话均可在停靠、收起按钮、浮层之间转换；Float 布局在当前界面显示 Agent 和 Debug 浮层。展开终端不再调用 wt.exe，不创建第二个 Windows Terminal 窗口或标签页。

2026-11-11 用户真机反馈明确了这一边界。此前独立 WT 小窗的实现已被替换；旧版产物与验证记录保留在 `artifacts/DevTabs-0.4.0-collapsible-terminals/` 和 `artifacts/floating-*.log`，它们不代表当前 UI。早期访谈中“小窗”和“置顶”的表述，以当前同界面浮层决定为准。

## 基本事实与实现边界

后台 ConPTY、shell、Agent 和日志进程属于宿主，呈现位置属于前端。收起、移动、缩放和停靠都不重新执行命令。会话身份始终是 WorkspaceId + SessionId，单个会话仅一个输入与尺寸租约所有者。

一套后台会话、现有 Ratatui 与 tui-term 渲染器足以完成需求。不增加桌面悬浮球、窗口管理进程、第二套终端模拟器或新依赖。外部已有 PowerShell／WT 标签页不在托管范围。

| 状态 | 当前界面 | 会话行为 |
| --- | --- | --- |
| Docked | 布局中的终端区域 | 对应前端附着、输入和调整尺寸 |
| Collapsed | 底部会话按钮 | 停止前端帧轮询，宿主继续读取输出和维护有界历史 |
| Floating | 当前 TUI 最上层终端面板 | 独占该会话租约；背景不重复显示同一会话 |

共享目标按宿主隔离，同一时刻只显示一个浮层终端。选择同项目另一终端或在另一项目展开终端，旧浮层会话收起，其进程继续运行。不同项目的浮层位于各自前端界面内，不在当前项目混入其他项目的命令。反复点击当前浮层按钮只聚焦，保持连接和尺寸。

## 界面与交互

底部会话栏固定一行，展示名称、呈现位置和真实命令状态。点击停靠项聚焦，点击收起项在当前界面展开浮层；右键或“会话”按钮打开完整列表。过长名称截断，过多会话通过菜单选择。

停靠终端标题提供“收起／悬浮”；浮层标题提供“收起／停靠／移动／尺寸”。宽度不足时统一显示 `[...]`，避免挤掉名称和焦点。所有终端都收起后工作区仍可操作，文件树、预览和未保存编辑保持。

浮层默认居中，宽为可用区域约 2/3（40～100 字符），高约 2/3（8～28 行），实际不超过可用区域。底部三行操作区始终保留。拖拽标题空白处移动；拖拽右下角 `◢` 及附近两格调整宽高。边界与整个拖拽手势由浮层接收，不透传到下方文件或终端。

浮层保持显示时可以点击背景工作、切换 Agent／Debug 焦点；普通键盘输入仅发送到实际聚焦且仍附着的会话。浮层内容点击／滚轮使用浮层局部坐标。选择、复制、历史和终端原生输入继续复用现有实现。位置变动本身不发送尺寸请求；重复尺寸由 Remote 去重。

键盘入口：先 Ctrl+G，松开，再按 W。

| 会话菜单按键 | 操作 |
| --- | --- |
| ↑↓／Home／End | 选择会话 |
| Enter | 聚焦或展开 |
| D／F／C | 停靠／悬浮／收起 |
| M／R | 将选定会话展开后进入移动／尺寸模式 |
| Esc | 关闭菜单 |

移动／尺寸模式用方向键调整，Shift 加速为五格，Enter 确认并保存，Esc 回到进入模式前的位置和尺寸。模式提示显示在浮层底边，普通字符和粘贴不发送给 shell。标题按钮也可进入模式。Ctrl+G T 作为移动当前浮层的快捷入口；不再切换操作系统窗口置顶。

Ctrl+G X 分离整个当前前端，Ctrl+G P 返回项目总览；它们保留既有未保存缓冲区确认流程。收起单个终端使用标题“收起”或会话菜单 C。结束整个工作区继续走已有关闭确认。

## 叠放与文件交互

绘制顺序为：停靠终端与文件面板、状态区、清空浮层矩形并绘制终端、终端操作按钮、文件弹窗、会话菜单、工作区关闭确认。浮层边框不会被背景文字覆盖；会话菜单和确认框保持最高交互优先级。浮层遮住的背景按钮移除点击范围。背景光标落在浮层覆盖范围时不显示；菜单和几何调整模式不显示终端光标。

浮层内的鼠标输入先于侧栏处理；已开始的文件拖拽则持有手势直到释放。释放目标使用当前真实可见的 Agent 内容区：支持 Agent 浮层，也禁止拖到 Debug 浮层时误投给背景 Agent。路径仍经异步验证、既有 Agent 状态检查与原输入链路发送，不自动回车。

原生 Sixel 图片与浮层共存：从图片可见区域中扣除终端浮层，直接裁切既有 Sixel 编码，绘制最多四个不重叠片段。图片尺寸和位置保持不变，浮层仅遮住重叠部分；移动、缩放、收起会局部清理旧像素并恢复可见区域。裁切结果使用有界缓存，静止浮层里的终端持续输出不会重复解码、量化、裁切或传输图片。独立图片、SVG 栅格结果和 Markdown 内嵌图片复用同一组合逻辑。实现和回归证据见 [30-Image-Panel-Composition.md](30-Image-Panel-Composition.md)。

## 宿主、生命周期和布局

复用准备→附着→提交握手：PrepareFloat 返回目标版本，准备阶段保留来源租约；成功创建目标 Client 才提交并撤下原呈现。附着失败取消该版本，原来源仍可用。旧版本、错误会话、无效尺寸和旧输入租约不能抢占目标。待提交请求 10 秒超时；前端崩溃后宿主在 3 秒租约超时加下一次清理周期内将浮层会话收起。

浮层使用当前 App 的 Client 和事件循环，删除了独立 WT 小窗启动、共享窗口互斥量、Win32 位置／尺寸／置顶恢复和独立浮动前端循环。协议里的原窗口启动标志也已删除。首次实现使用 DevTabs-v4；后续配置字段升级发现同版本不同构建仍会混用旧宿主，因此当前改为 DevTabs-v5 并加入自动生成的构建标识，详见 [31-Host-Build-Isolation.md](31-Host-Build-Isolation.md)。旧版正在运行的会话由旧版正常结束，新版不迁移旧进程。旧的隐藏 `--view floating` 明确报错，不能悄悄打开第二个前端。

Float／Split 只改变停靠终端的布局；已有浮层保持会话、租约和进程。进入 Tabs 时若浮层仍在，保留当前前端呈现，避免分离浮层；无浮层时继续原有原生 Tabs 行为。初次 Float 默认展开 Debug；重连不会撤销用户明确的收起决定，切布局也不会用默认 Debug 覆盖显式浮层目标。

正常退出当前 App 会释放各 Client。宿主继续托管进程，浮层状态回到收起。共享目标切换后原前端只移除旧浮层，文件区域和其他停靠会话保持可用，不因旧租约失效退出整个项目。

## 位置与尺寸保存

`%APPDATA%\DevTabs\terminal-panel.json` 保存 `[x, y, width, height]`，单位为终端字符格。使用 --data-dir／DEVTABS_HOME 时随数据目录隔离。读取最多 1 KiB，损坏或过大时使用默认布局；拖拽释放或键盘确认后原子保存。每次使用时约束到当前 TUI 可用区域，窗口变小不会把浮层留到界面外。

当前 App 内收起／恢复保留几何状态；新前端读取最后保存的状态。各已运行前端保留自己的内存状态，不增加跨前端配置广播。位置与大小不持久化 HWND、PID 或会话租约；不读取旧的屏幕像素坐标配置 `floating-window.json`。

## 源码落点

- `src/app/popup.rs`：有界字符几何、位置持久化、拖拽捕获、键盘调整和事务式浮层附着。
- `src/app/terminals.rs`：统一会话按钮、菜单、状态同步、层级对应的点击区域。
- `src/app.rs`：停靠与浮层矩形、可见附着、输入隔离、布局切换、文件拖放目标。
- `src/ui.rs`：共用终端渲染、浮层清空与叠放、边框和光标遮挡。
- `src/sidebar.rs`：接收实际可见 Agent 区域，继续原有拖放、验证和输入流程。
- `src/presentation.rs`、`host.rs`、`protocol.rs`：稳定目标、切换版本、唯一租约及崩溃回收。
- `src/windows.rs`：仅保留原有工作区窗口／标签启动与聚焦，悬浮操作没有 WT 调用。
- `src/i18n/*.json`：浮层操作和调整模式中英文文案，继续使用 rust-i18n。

## 验证

修改前基线为上一版 284 项通过、0 失败、23 项默认忽略，见原独立构建 `build.json`。本次移除已不再适用的原生 WT 小窗真机测试与像素几何测试，以同一前端内的完整浮层测试及字符几何测试替换。原宿主握手、进程身份、后台输出、过期输入和无效尺寸测试继续保留。

自动化使用 Ratatui TestBackend 和隔离后台 ConPTY，Agent 使用 shell fixture，不启动本机 Codex／Claude。隔离前端 PATH 的 wt.exe 使用会拒绝 WT 参数的测试替身，避免回归意外打开真实窗口。

覆盖项目：

- 默认 Float 在启动它的同一前端绘制 Debug；循环切换布局仍保留浮层。
- 收起／恢复、停靠、全会话收起后重新展开，UUID 和 shell PID 不变。
- 标题拖动、右下角缩放、键盘调整和取消、坐标保存恢复。
- 向浮层实际发送命令，跨项目切换共享目标后原前端仍可输入。
- 强杀持有浮层的前端后宿主回收，重连保留用户收起决定。
- 背景文本清空、边框遮挡、菜单层级、窄栏与中英文点击范围。
- 文件拖到 Agent 浮层进入既有验证链路，拖到 Debug 不投到背景。
- 未保存编辑保留，既有文件、Markdown／代码／SVG／图片、保存和性能回归。
