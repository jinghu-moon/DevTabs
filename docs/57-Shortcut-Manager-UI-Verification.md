# 快捷键管理界面重写与验证

日期：2026-11-15。基线提交：`7d43765`。本轮按用户提供的 `D:/000_Inbox/020_Browser/021_Edge/DevTabs 快捷键管理 · 终端风格演示.html` 及预览图重写实际 Ratatui 页面。独立管理视图继续属于统一设置事务，不引入新的配置文件或快捷键执行器。

## 参考稿与实际界面

| 参考部分 | 实际实现 |
| --- | --- |
| 顶部搜索与状态 | 可点击的搜索框，按名称、命令 ID、区域及有效键查找；显示共同草稿的未保存/已保存状态，右上角关闭 |
| 六组计数筛选 | 全部、当前区域、已修改、未绑定、内部冲突、含删除备注；由真实命令注册表与差异计算，计数不受搜索词干扰 |
| 左侧四列表格 | 功能、区域、全部有效别名、默认/自定义来源；首选显示排在前面，长集合截断后可在详情逐条查看 |
| 常用项目在前 | 便签、收藏、设置、刷新、历史、队列、命令面板、快捷键管理及常用编辑命令排前，其他真实命令继续完整列出 |
| 右侧当前命令 | 名称、ID、功能说明、生效区域、允许作用域、默认、来源、状态、删除历史与备注；显示不同区域同键复用，保留实际诊断 |
| 逐条绑定按钮 | 修改、删除、删除并附备注、设为首选；添加绑定、恢复当前命令、按键测试直接可点击 |
| 录制及输入区 | 在详情区内显示组合键/序列录制、文本输入、备注、风险与导入预览；完成/取消固定在该区域底部，Esc/Enter 仍能被录制 |
| 测试面板 | 可选择区域、查看有效/草稿解析及原生物理记录、清空会话记录、一键设首选；切区域清除旧候选；不执行命令或发送终端输入 |
| 底部操作 | 保存全部共同草稿、取消、恢复全部默认、备份/导入/导出、返回设置；取消沿用保存/放弃/继续编辑保护 |
| 窄窗 | 108 列以下切换列表/详情；低高度压缩筛选，编辑时优先给独占表单空间；按钮换行不与说明叠放 |

颜色继续跟随应用主题。按键使用强调色，Light 主题使用可读的深金色；选中行用主题底色。按终端单元格宽度计算列和截断，绘制与鼠标命中使用同一布局。列表与详情滚轮分别作用于所在区域，详情另有可点击翻滚按钮。

参考稿的十二个演示命令没有替代正式目录；实际显示完整注册表。默认仅为已确认的 F3 提供 Ctrl+F3 别名，没有照搬 Ctrl+F2/Ctrl+F4 等机械别名。「外部保留」按既定规格合并为删除并附用户备注，不创建外部占用规则；备注不参与匹配。备份/导出区分可导入的已保存 TOML 差异与仅供查看的有效 JSON 目录，保持导入先预览与覆盖前确认。

宽窗和窄窗都保留所有高级能力：作用域、停用/启用、序列录制、原前缀配置、恢复删除键、清理备注、失效项处理、导入导出。较少使用的功能集中到「更多操作」，不将全部按钮挤在一个底栏。

## 实现与输入边界

- `src/settings/shortcut_ui/view.rs` 负责呈现与命中；`shortcut_ui.rs` 复用既有校验、录制、风险确认和差异编辑。
- `src/settings/ui.rs` 在快捷键分类使用全宽管理页，保留同一个 Draft、原子保存、冲突与关闭保护；标题明确保存全部分类，而不是局部提前应用。
- 总览和工作区入口传入实际来源区域，避免「当前区域」始终等于终端。
- 模态录制/测试独占输入，背景列表、外层保存/关闭不接收其按键或鼠标。测试候选只属于收到按键时的区域。
- 没有新配置格式、默认 Fn 别名、全局钩子或外部软件设置修改。
