# Overview Detail and Interaction Fixes

## 1. 目标

修复总览中详情缺乏层次、用户与 AI 对话难以区分、搜索文字无法点击，以及空闲后出现 `Connect to DevTabs host: 系统找不到指定的文件。(os error 2)` 四个问题。参考旧项目的角色徽标、正文竖线、分区标题和填充式筛选标签，保留现有 Markdown 渲染器、后台采集和启动草稿模型。

## 2. 详情与搜索

- 详情顶部显示与项目列表一致的项目色块、加粗名称及弱化路径。区块标题以横线延伸至当前内容宽度；下一步、启动选项、改动文件、最近对话和最近提交不再混为连续正文。
- 用户使用琥珀色徽标与竖线，AI 使用蓝色徽标与竖线，明确显示“你 / AI”（英文为 You / AI）。浅色主题采用较深的对应颜色与白色徽标文字，深色主题使用浅色徽标与黑色文字。
- 对话正文继续使用共享 Markdown 渲染。先扣除竖线占用的两格，再排版；长代码行也在摘要内换行，每条续行保留角色竖线和原有代码样式。不会改变文件预览的横向滚动行为。
- 保持最近 2 段、每段默认最多 5 行，展开最多 6 段、每段 120 行；保留输入长度预算和按项目、Agent、会话、栏宽、主题及语言索引的摘要缓存。
- 搜索框拥有实际鼠标命中区域、占位提示、焦点样式和光标。点击或 `/` 聚焦，输入即时筛选，Backspace 删除，Enter / Esc 返回列表；已经聚焦后输入 `/` 会作为路径内容保留。
- 长搜索词从尾部显示，按终端格宽和完整字素计算，支持中文、组合字符和 emoji。窗口缩小至最低尺寸以下时清除命中区域；模态弹窗与详情浮层不会向底层搜索框透传点击。
- 顶部固定两行：品牌 / 搜索 / 排序，以及筛选标签。标签使用背景填充、间距和琥珀色选中态，取消下划线。窄窗口优先保证当前筛选可见，其余筛选仍可通过 F6 切换。

## 3. 宿主故障根因与修复

原宿主只依据“无工作区超过 30 秒”决定退出，即使总览仍在轮询。总览后台仅启动时执行一次 `host::ensure()`，之后只发 List；宿主退出后没有恢复路径，所以命名管道不存在错误会一直出现。

现在空闲超时以“无工作区且没有客户端请求”为条件。总览轮询会保留正在使用的空宿主；关闭总览且无工作区后，仍会自动退出。若宿主崩溃或退出，后台状态查询遇到明确的传输断线错误时执行一次 ensure 并重试 List。每次轮询最多恢复一次，仍使用原有 2 秒间隔和启动超时，不增加 UI 线程 I/O，不创建终端或 Agent 会话。

权限错误、非法响应和宿主返回的应用错误不会被认作普通断线，也不会冒充“没有运行中的工作区”。持续错误显示简短的“连接中断，正在重连”提示；点击可打开诊断查看完整错误与构建标识。成功查询会清除错误并恢复运行数。

## 4. 验证

升级前基线与故障复现、升级后完整回归、Clippy、格式和 Release 检查日志统一收录于独立测试包。具体计数和构建信息见本节最终结果及包内 `build.json`。

新增自动化验证覆盖：

1. 鼠标聚焦搜索 → 输入 → 列表筛选 → 删除恢复；中文 / 英文几何；路径中的斜杠；弹窗阻断及缩窗清理。
2. 60 / 80 / 104 / 140 / 160 / 200 列的长 Unicode 搜索词、可见光标、筛选选中背景和当前标签可见性。
3. 用户与 AI 徽标颜色不同、正文竖线匹配角色、Markdown 加粗及代码保留、长代码有界换行、缓存和本地链接保持。
4. 宿主错误保持未知、详情简短提示可点击、诊断完整错误可见、恢复后状态清除；权限错误不触发普通断线恢复。
5. 隔离 ConPTY 总览启动空宿主 → 关闭宿主 → 总览自动恢复到新的宿主 PID，前后工作区数量均为零。升级前同一用例在 8 秒内无法恢复；升级后通过。

本轮不启动真实 Windows Terminal 或已安装的 Codex / Claude；真机 UI 由用户验收。
