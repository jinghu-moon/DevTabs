# 工作区界面与交互统一

参考：`refer/DevTabs 界面参考稿.html`。本次将可迁移的视觉与交互规则落实到 Ratatui 字符格布局，沿用现有终端、文件树、编辑器与图片合成能力，无新增依赖。

## 已实现项目

1. **单行全局底栏**：左侧文件树入口，中间实际键盘目标及操作提示，右侧紧凑终端按钮与会话菜单。操作结果临时替换提示；前端消息六秒后恢复，持续 I/O 错误继续显示。文档模式、阅读进度留在预览下边框。
2. **Ctrl+G 命令菜单**：显示真实前缀命令；按对应键或点击执行，Esc 或点击外部取消。菜单与键盘复用同一个命令分发器；小窗口增加列数。吞掉完整鼠标手势及已消费按键的释放事件，避免输入泄漏。
3. **统一焦点**：终端边框、终端底栏按钮、树选中行与底栏提示读取实际键盘目标。悬停展示按钮，不抢键盘焦点；失焦树保留行定位，取消强调色。
4. **简洁标题**：终端常态显示 `Agent · Codex`、`Debug` 或会话名称；只读文件显示文件名和只读状态；编辑器显示文件名、编辑状态与实际未保存标记。异常、退出码、保存中和外部冲突按需保留。
5. **按需标题操作**：聚焦或悬停时展示操作；其他时候保留更多入口。预览绘制与点击统一使用可见按钮列表，终端每帧重建真实按钮命中区。隐藏按钮无命中区域。
6. **浮窗层次**：区别于主界面的背景，右侧和底部一格阴影。终端自带的显式前景/背景色保留；只填充默认背景。阴影连同浮窗一起裁剪图片。先绘制基础面板，再绘制浮窗，最后绘制菜单/对话框，避免标题与标签覆盖浮窗。
7. **Git 语义颜色**：`M/R` 黄色、`?/A` 绿色、`U/D` 红色、忽略项灰色；保留字母标识，浅色主题使用更深的对应颜色。链接和预览标记独立着色。
8. **紧凑有边框标签**：保留三行完整边框及明确的当前标签背景/边框；减少标签宽度，容纳更多文件。`●` 专用于真实未保存状态，当前选中不再使用它。Markdown/源码模式在文档边框明示，重复文件名仍能显示父路径。
9. **显式聚焦放大**：Ctrl+G → Z 放大当前树、预览/编辑器或终端；重复还原。目标在触发时确定；离开或关闭该目标时结束放大、恢复原布局。常态下焦点变化不自动改变宽度。手动栏宽、Agent 比例和浮窗尺寸不被放大动作写回；放大期间暂停分隔线调整。终端进程保持原身份，隐藏的浮窗不再拦截鼠标。
10. **真实提示**：底栏只展示 DevTabs 管理的键位，不假设 Codex、Claude 或 shell 内部快捷键。图片预览使用自己的提示。不会照搬参考稿的裸 G 或演示性 Space/路径提示。

新增文本纳入既有 `rust-i18n` 中英文资源，终端输出、路径和文件内容保持原值。字体仍由用户的终端配置决定。

## 布局与性能边界

全局底栏由三行降为一行。实际工作区 140×36 的正文由 33 行增加到 35 行；40 行窗口由 37 行增加到 39 行。预览原有四周留白与标签边框继续保留。直接使用 Sidebar 布局 API 的测试由预留两行改为一行，前端不再额外减一行。

普通焦点切换只更新强调样式与可见按钮，不改面板尺寸、不触发 PTY 尺寸变化。显式放大、手动拖动和终端窗口调整才改变布局，无宽度动画。图片阴影遮挡沿用已有编码裁剪与缓存，不重新解码整图。
