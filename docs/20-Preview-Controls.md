# Preview Controls

## 范围

完成预览扩展中的 1–6、8；第 7 项图片内嵌预览暂缓。沿用 Ratatui、现有后台任务、编辑缓冲区与未保存确认流程，不增加依赖。

## 工具栏与标签

- 常用动作使用可读标签；`[More]` 与 `F2` 打开完整动作菜单，支持鼠标单击选择、滚轮选择与点击外部关闭。根据宽度收起按钮，为文件名保留空间。
- Markdown 大纲按钮显示 `[T]Headings`，仍打开预览右上角的下拉弹窗；菜单保留源码模式、对照、换行、差异等入口。
- 不可用操作显示灰色；菜单中的换行、对照、最大化、Markdown 模式显示开关状态。
- 保留已确认的三行四边框标签、激活背景及标签下方间距。标签右侧 `×` 和鼠标中键关闭对应文件；右键菜单支持复制绝对路径、关闭当前标签、关闭其他、关闭右侧。
- 后台标签不保留脏缓冲区。批量关闭若包含当前未保存文档，先提示保存/放弃/取消；取消保留全部标签与缓冲区。
- 保留最多 8 个标签。打开第 9 个文件时淘汰最早标签，并提示被关闭的文件路径。
- 同名文件追加父目录；父目录也同名时显示项目内更长路径。悬停标签或标题显示完整绝对路径。
- `Alt+C` 复制当前文件绝对路径；右键标签可以复制该标签路径，不需要先切换文件。

## 阅读历史

`Alt+Left` 后退，`Alt+Right` 前进，工具栏空间充足时提供 `[<]`、`[>]`。

历史覆盖文件切换、标题/脚注跳转、行号与百分比定位、搜索跳转、书签跳转。记录源位置、横向位置、阅读/源码模式与 details 展开状态。前后栈各限制为 64 项；滚轮不产生历史。开始新跳转会清空前进栈，打开空搜索后取消不会清空。

跨文件历史与普通文件打开使用相同未保存确认；取消不移动历史指针。后台读取队列拒绝请求时保留原历史。历史只保存在当前前端内存中，重启后需要继续阅读的位置使用书签。

## 差异阅读

`D` 打开已有差异视图。新增：

| 操作 | 按键 |
| --- | --- |
| 下一处差异块 | `n` / `]` |
| 上一处差异块 | `Shift+N` / `[` |
| 复制完整 unified diff | `C` |
| 关闭 | `Esc` |

上下、左右、PageUp/PageDown 和滚轮继续可用。块索引来自 unified diff 的 `@@` 行；复制完整原始补丁，不复制屏幕截断内容。无差异时导航无操作。

## 持久阅读书签

| 操作 | 按键 |
| --- | --- |
| 为当前阅读位置添加书签 | `B`，输入备注后 `Enter` |
| 打开当前项目书签 | `Ctrl+B` / More → Reading bookmarks |
| 选择 / 跳转 | 上下方向键 / `Enter`，或单击条目 |
| 编辑备注 | `E` |
| 删除所选书签 | `Delete` |
| 重新加载其他前端的修改 | `R` |
| 关闭 / 取消备注输入 | `Esc` |

备注上限 256 字符。书签存绝对文件路径、源字节位置、源行号、当前源行的前 128 字符及阅读模式。恢复时优先匹配最近的相同源行；源行已被修改时回退到保存行号/有界字节位置。文件变化后这是尽力定位，不保证语义位置始终相同。文件不存在或读取失败时显示原有读取错误。

书签位于当前数据目录的 `bookmarks.json`，默认 `%APPDATA%\DevTabs\bookmarks.json`；遵循 `--data-dir` / `DEVTABS_HOME`，按项目隔离。每项目 128 项，全局 4096 项，存储文件不超过 8 MiB。后台线程执行读取、更新；在既有配置锁内重新读取、合并、原子替换，避免多个前端相互覆盖。只有收到后台完成通知才提示已保存；取消弹窗不撤销已经提交的后台保存。解析、版本或写入失败保留原文件并显示错误，可修复后重试。

## 文件信息

`I` / More → File information 打开浮层，显示：

- 文件绝对路径、实际磁盘大小、已加载字节数。
- UTF-8 / UTF-8 BOM / UTF-16 LE / UTF-16 BE、LF / CRLF；混合换行等细节保留读取提示。
- 修改时间（UTC）、是否截断、是否允许编辑。
- `C` 复制全部信息，`Esc` 关闭。

信息取自最近一次读取/保存的文件句柄元数据。绘制不访问磁盘；手动刷新或文件监听读取完成后更新。未保存的编辑缓冲区不改变磁盘信息。
